# Política de marcas do Concat

O código-fonte do Concat é software livre sob a licença AGPL-3.0-or-later[cite: 10]. O nome e o logotipo do Concat não fazem parte dessa concessão[cite: 10].

Isso é deliberado e padrão: a AGPL, como toda licença GNU, não concede direitos de marca comercial (veja a seção 7(e) da AGPL-3.0)[cite: 10]. Mozilla, Docker e o projeto Rust separam ambos da mesma forma[cite: 10]. O código é seu para criar forks; o nome identifica as compilações que vêm deste projeto, para que quem baixar o "Concat" saiba exatamente o que está obtendo[cite: 10].

## As marcas

- A marca nominativa Concat, como o nome deste editor de vídeo[cite: 10].
- O logotipo do Concat e suas variações, em `assets/`[cite: 10].

Os direitos autorais e as marcas são de titularidade de Jareer Abdullah (GitHub: [@jub0t](https://github.com/jub0t))[cite: 10].

## O que você pode fazer sem pedir autorização

- Dizer o que seu software é[cite: 10]. O uso nominativo é sempre permitido: "um plugin para o Concat", "compatível com o Concat", "um fork do Concat", "importa projetos do Concat"[cite: 10]. Descreva a relação de forma precisa e não precisará de autorização[cite: 10].
- Redistribuir compilações oficiais sob o nome Concat, de forma não modificada[cite: 10].
- Empacotar o Concat para distribuições (Nix, Homebrew, AUR, Debian, Flatpak...) a partir do código original não modificado, mantendo o nome[cite: 10]. Patches restritos a empacotamento, caminhos e flags de compilação são aceitos[cite: 10].
- Escrever sobre o Concat: análises, tutoriais, vídeos, capturas de tela, comparações e trabalhos acadêmicos[cite: 10]. Nenhuma permissão é necessária nem solicitada[cite: 10].
- Usar o logotipo para criar links ou referenciar este projeto[cite: 10].

## O que exige um nome diferente

Se você distribuir uma versão modificada do Concat, use seu próprio nome e seu próprio ícone[cite: 10]. Concretamente, renomeie antes de distribuir caso você[cite: 10]:

- altere o comportamento do editor, o motor gráfico, os padrões ou os modelos incluídos[cite: 10];
- adicione ou remova recursos e distribua o resultado para terceiros[cite: 10];
- distribua compilações que os usuários possam confundir com as oficiais[cite: 10].

Você mantém todos os direitos que a AGPL lhe concede: faça forks, altere, venda, hospede[cite: 10]. Apenas use outro nome, para que relatórios de erros e reputação cheguem ao lugar certo[cite: 10]. Forks são bem-vindos; esse é o objetivo da licença[cite: 10].

## O que não é permitido

- Apresentar uma compilação modificada como o Concat oficial[cite: 10].
- Usar Concat ou um nome confusamente semelhante no nome do seu produto, empresa, listagem em lojas de aplicativos ou domínio de modo a sugerir endosso ou manutenção por este projeto[cite: 10].
- Usar o logotipo como ícone ou identidade visual do seu próprio produto[cite: 10].
- Registrar a marca Concat, ou uma confusamente similar, em qualquer jurisdição[cite: 10].

Para casos não previstos acima ou uso que você queira autorização explícita: jub0trd@gmail.com[cite: 10]. Pedidos razoáveis recebem resposta positiva[cite: 10].

Esta política pode ser atualizada[cite: 10]. As alterações não retroagem contra usos permitidos no momento em que foram feitos[cite: 10].
